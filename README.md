# Барометр

Локальный сайт для расчёта давления по этажам и оценки высоты этажа по измерениям.

## Запуск на компьютере

Нужен Python 3. Откройте Терминал и выполните:

```bash
cd "/Users/romandemcenko/Desktop/Dev/Python/Барометр"
python3 run_site.py
```

Затем откройте [http://localhost:8000](http://localhost:8000) в браузере. Для остановки сервера нажмите `Ctrl+C` в Терминале. Интернет и установка пакетов для основной страницы не нужны. Данные, введённые на локальном адресе, сохраняются отдельно от опубликованного сайта.

Если порт 8000 занят, запустите вручную другой:

```bash
python3 -m http.server 8001 --bind 127.0.0.1 --directory dist
```

Тогда адрес — [http://localhost:8001](http://localhost:8001).

## Что умеет сайт

- Верхняя таблица рассчитывает давление на каждом этаже по высоте между этажами и одному опорному замеру.
- Нижняя таблица принимает несколько пар «номер этажа — давление» и рассчитывает высоту между измерениями и среднюю высоту одного этажа. Кнопка подставляет среднюю высоту в верхнюю таблицу.
- Используется формула `Δh = R × (T + 273,15) / g × ln(Pнижнего / Pверхнего)` при `T = 20 °C`, `R = 287,05 Дж/(кг·К)`, `g = 9,80665 м/с²`.
- Погода и вентиляция влияют на давление. Для сравнения этажей снимайте показания одним телефоном за короткое время.

## Файлы

- `dist/index.html` — основная страница без сборки и внешних библиотек.
- `dist/position.html` — экспериментальная страница для GPS, компаса и плана; откройте [http://localhost:8000/position.html](http://localhost:8000/position.html).
- `ios/Barrometr.xcodeproj` — проект iOS-приложения; для запуска нужен Xcode и iPhone.
- `barometer.py` — отдельная Python-функция оценки высоты по давлению.
- `.openai/hosting.json` — настройки публикации существующего сайта.

Локальный запуск и публикация сайта — разные процессы. Изменение локальных файлов не обновляет опубликованную версию автоматически.
