# Моя высота

Веб-приложение для примерной оценки высоты над уровнем моря и этажа на iPhone и других устройствах с геолокацией.

## Как пользоваться

1. Откройте [сайт](https://barrometr-height-2026.heartyapple9.chatgpt.site) на телефоне и нажмите **«Определить высоту»**.
2. Разрешите браузеру доступ к геолокации.
3. Для оценки этажа измерьте высоту у входа или на первом этаже, нажмите **«Запомнить уровень земли»**, затем поднимитесь и повторите измерение. Калибровка действует 30 минут и только рядом с исходной точкой.

Если браузер не передаёт высоту устройства, приложение показывает высоту земной поверхности по [Open-Meteo Elevation API](https://open-meteo.com/en/docs/elevation-api). В этом режиме можно вручную добавить высоту над землёй. Оценка этажа исходит из 3 м на этаж.

## Точность и данные

- Браузер не предоставляет сайту прямой доступ к барометру iPhone. Давление воздуха здесь не используется, поэтому ежедневные изменения давления не входят в расчёт. Высота устройства, когда доступна, приходит через Geolocation API.
- Оценка этажа особенно чувствительна к ошибке вертикальной геолокации. Сравнивайте измерения, сделанные поблизости и с небольшим интервалом. Для надёжного определения этажа понадобится отдельное приложение iOS с доступом к Core Motion.
- Карта рельефа Copernicus DEM GLO-90 имеет разрешение около 90 м и не учитывает здания. Данные предоставляются через Open-Meteo.
- Координаты отправляются в Open-Meteo только при запросе высоты рельефа. Калибровка уровня земли хранится в памяти страницы до её закрытия или обновления.

## Структура

- `dist/index.html` — сайт без сборки и внешних зависимостей.
- `barometer.py` — отдельная функция расчёта высоты по двум измерениям давления. Веб-сайт её не вызывает.
- `.openai/hosting.json` — настройки публикации в Sites.

## Локальный запуск

```bash
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Геолокация работает в безопасном контексте: через HTTPS или на `localhost`.

## История и откат

Каждое изменение следует сохранять отдельным коммитом. Посмотреть историю:

```bash
git log --oneline
```

Для безопасного отката опубликованного изменения создайте обратный коммит:

```bash
git revert <commit_sha>
```

Затем опубликуйте получившуюся версию через Sites. Один `git revert` меняет исходники, но не переключает уже опубликованный сайт автоматически. При необходимости можно заново развернуть сохранённую старую версию в Sites.
