# Высота по давлению

Веб-приложение для оценки высоты **от первого этажа** и текущего этажа по двум показаниям барометра. [Открыть сайт](https://barrometr-height-2026.heartyapple9.chatgpt.site).

## Как пользоваться

1. Выберите здание: готовые профили **«Университет» (3,3 м)** и **«Дом» (2,7 м)** или добавьте свой корпус. На его первом этаже считайте фактическое атмосферное давление с барометра, введите показание в гПа или кПа и нажмите **«Сохранить первый этаж»**.
2. Поднимитесь и тем же устройством измерьте давление снова. Введите второе показание и нажмите **«Рассчитать высоту и этаж»**.
3. При необходимости сохраните результат в историю. Нулевой замер и история останутся в этом браузере для будущих дней.

В последующие дни не нужно возвращаться на первый этаж. На **любом известном этаже** введите его номер и текущее давление в блоке **«Обновить ноль без похода вниз»**. Сайт восстановит расчётное давление первого этажа и применит свежую калибровку ко всем сохранённым высотам. Если для выбранного этажа записана точная высота, используется она; иначе применяется шаг здания. Чтобы дома проверить расчёт без барометра, используйте зелёную плашку с ручной высотой над первым этажом.

Нужны **фактические показания давления в месте измерения**. Давление из прогноза погоды, приведённое к уровню моря, и высота GPS в метрах не подходят. Обычный Safari не предоставляет веб-странице доступ к барометру. Для автоматического ввода есть iOS-приложение в `ios/Barrometr.xcodeproj`: оно отображает тот же интерфейс и получает давление через Core Motion. В Safari остаётся ручной ввод.

## Автоматическое измерение на iPhone

1. Установите полную версию Xcode из App Store на Mac и откройте `ios/Barrometr.xcodeproj`.
2. В настройках target **Barrometr → Signing & Capabilities** выберите свою команду разработчика. При конфликте идентификатора измените `PRODUCT_BUNDLE_IDENTIFIER`.
3. Подключите iPhone, выберите его как устройство запуска и нажмите **Run**. На телефоне разрешите доступ к данным движения.
4. Откройте приложение «Баррометр». Дождитесь показания в зелёной плашке. На первом этаже нажмите **«Сохранить первый этаж с iPhone»**; на другом — **«Рассчитать по барометру iPhone»**. Для новой калибровки на известном этаже укажите только номер этажа и нажмите **«Обновить ноль по этому этажу»**.

Приложение считывает `CMAltitudeData.pressure` в кПа, переводит в гПа и усредняет последние пять показаний. HTML включается в приложение при сборке, поэтому оно работает без доступа к опубликованному сайту. Состояние приложения сохраняется на iPhone через `UserDefaults`; данные сайта в Safari находятся в отдельном хранилище и автоматически не переносятся. После изменения `dist/index.html` приложение нужно собрать заново.

В текущей рабочей среде доступен только Xcode Command Line Tools, поэтому проект проверен на синтаксис и структуру, но сборка и работа с физическим барометром должны быть проверены в полном Xcode на iPhone.

## Расчёт

Пусть `p₁` — давление первого этажа, `p₂` — давление текущего этажа. Высота относительно первого этажа:

```text
Δh = R · (T + 273,15) / g · ln(p₁ / p₂)
R = 287,05 Дж/(кг·К), g = 9,80665 м/с²
```

`T` — температура воздуха в °C, по умолчанию 20 °C. При подъёме давление обычно падает, поэтому `Δh` положительна. Первый этаж имеет номер 1; без отдельных калибровок оценка равна `max(1, round(Δh / 3,3) + 1)`. Между полами этажей по умолчанию 3,3 м. Для каждого корпуса можно изменить шаг и сохранить высоту отдельных этажей. Эти отметки имеют приоритет при выборе ближайшего этажа.

Пример: 1002,4 гПа на первом этаже и 1001,2 гПа наверху при 20 °C дают около 10,3 м и примерно 4-й этаж для университета. Для дома этажность считается с шагом 2,7 м.

Если известный этаж имеет высоту `hₖ`, а текущее давление там `pₖ`, новый виртуальный ноль первого этажа: `p₁ = pₖ · exp(hₖ · g / (R · (T+273,15)))`. Калибровка требует, чтобы пользователь **знал**, на каком этаже находится. Только по одному давлению нельзя отличить подъём от погодного сдвига.

## Точность и сохранение

- Для этажа с шагом 3,3 м разница давления составляет примерно 0,38 гПа; ошибка 0,2 гПа даёт около 1,7 м, то есть половину этажа. Нужен датчик с достаточным разрешением; округлённые до целого гПа показания не годятся.
- **Фиксированного срока актуальности нет.** По шкале Met Office даже «медленное» изменение давления составляет 0,1–1,5 гПа за 3 часа, а при быстром изменении может достигать 3,6–6,0 гПа за 3 часа. Напоминание через 30 минут — практический сигнал проверить калибровку, но не гарантия точности до этого момента. Вентиляция и потоки воздуха добавляют локальные ошибки.
- Для снижения погрешности используйте один и тот же датчик, снимайте 3–5 показаний после стабилизации в одной точке и вводите их через `;` — сайт усреднит. Разброс более 0,2 гПа помечается как нестабильный. Не держите телефон у вентиляции или открытого окна. В новом сеансе обновляйте ноль по известному этажу; все этажи обходить заново не надо.
- Горизонтальная точность GPS 1–3 м не означает такую же точность высоты. Сайт не использует GPS для определения этажа.
- Полностью автоматический погодный сдвиг потребовал бы постоянного опорного датчика в здании. Данные удалённой метеостанции могут быть недостаточно точны для различения соседних этажей. Автоматически читать барометр iPhone сможет отдельное приложение на Core Motion, но ему всё равно нужна поправка на сдвиг давления.
- Ноль хранится отдельно для каждого корпуса; история ограничена 100 последними результатами. Данные лежат в `localStorage` браузера, не синхронизируются между устройствами и удаляются при очистке данных сайта.
- Старые замеры, сделанные по высоте геолокации, не используются как барометрический ноль.

Источники: [Met Office — изменения давления](https://weather.metoffice.gov.uk/guides/coast-and-sea/glossary), [Met Office — особенности измерения в зданиях](https://weather.metoffice.gov.uk/guides/observations/how-we-measure-atmospheric-pressure), [Apple — CMAltimeter](https://developer.apple.com/documentation/coremotion/cmaltimeter).

## Структура и запуск

- `dist/index.html` — приложение без сборки и внешних зависимостей.
- `ios/Barrometr.xcodeproj` и `ios/Barrometr/*.swift` — iOS-оболочка с Core Motion и локальной страницей.
- `.openai/hosting.json` — конфигурация публикации в Sites.
- `barometer.py` на уровень выше — отдельная Python-функция; сайт её не вызывает.

```bash
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`.

## История версий и откат

Изменения хранятся в Git. Просмотр истории:

```bash
git log --oneline
```

Для отмены опубликованного коммита создайте обратный коммит:

```bash
git revert <commit_sha>
```

После этого новую исходную версию нужно опубликовать через Sites: сам `git revert` работающий сайт не переключает.
